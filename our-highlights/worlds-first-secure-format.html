From Server Trust to Cryptographic Verification

Traditional cloud storage models operate on server-side trust: plaintext files are transmitted over networks to remote servers, which encrypt them with cloud-managed keys. This architecture introduces critical vulnerabilities, including server hypervisor intrusions, database leakage, insider exploits, and subpoena exposure.

Coralgenz Global engineered the .secure file format to render server-side compromises mathematically impossible. Files are parsed, salted, encrypted, and encapsulated directly inside the client's browser using WebCrypto APIs before any byte leaves the machine.

STEP 01
Source File Selection

Target document, image, audio, or binary read via local File API.

STEP 02
Key Derivation

PBKDF2 / Argon2id generates 256-bit key from user passphrase + random salt.

STEP 03
AES-GCM-256 Engine

Cryptographic encryption with 96-bit unique IV & 128-bit GMAC integrity tag.

STEP 04
Envelope Packaging

Binary header, metadata, salt, IV, and ciphertext packaged into .secure payload.

STEP 05
Zero-Knowledge Export

Single atomic .secure file exported. Server only ever receives encrypted blobs.

SPECIFICATION BLUEPRINT BINARY LAYOUT V1.0

.secure Binary Envelope Specification

The .secure container format follows a rigid, tamper-proof binary standard engineered for universal compatibility and instant client-side decryption:

.secure CONTAINER STRUCTURE WebCrypto Native
BYTES 00 - 15 Magic Header: "CGZ_SECURE_V1_ENV" 16 Bytes ASCII
BYTES 16 - 31 Cryptographic Salt (PBKDF2-HMAC-SHA256) 16 Bytes Cryptographic
BYTES 32 - 43 Initialization Vector (AES-GCM IV) 12 Bytes (96-Bit Nonce)
BYTES 44 - 47 Original Metadata Header Length 4 Bytes Big-Endian
BYTES 48 - (48+M) Original MIME Type & Filename String UTF-8 Encoded JSON
PAYLOAD SECTION Authenticated Ciphertext N Bytes AES-GCM
TRAILING 16 BYTES Galois Message Authentication Code (GMAC) 16 Bytes Integrity Tag

Zero Server Telemetry

Decryption passphrases never hit server memory, databases, or logs. Security is mathematically self-contained.

Hardware Accelerated

Leverages native AES-NI hardware instruction sets via browser WebCrypto for multi-gigabyte throughput.

Autonomous Browser Decryption

Recipients require zero desktop software installs. The built-in runtime unlocks files in any browser instantly.

Tamper-Evident Integrity

Any single-bit modification during transfer causes GMAC validation failure, preventing MITM injections.
